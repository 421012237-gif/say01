# 怎么把表情加进微信

先打开本包的 preview.html 看动态效果。要取原文件，请打开 stickers 文件夹；static 文件夹是静态备份。截图不能保留动画。

1. 先选择一张 stickers 里的 .gif 文件，发送到你自己的微信“文件传输助手”。
2. 打开该聊天，使用当前微信版本提供的“添加到表情”操作。手机通常可以长按图片，电脑按实际菜单操作；只有加入个人表情才算完成，“收藏”是另一个功能。
3. 打开聊天的表情面板，在个人添加的表情区域查找，点一次试发给文件传输助手。
4. 确认第一张成功后，再添加其余GIF。不同微信版本是否支持批量添加，以你实际看到的入口为准。

个人聊天使用无需先公开上架表情专辑。本包尚未替你添加、发送或投稿。

## 如果遇到问题

- 缩略图不动：先打开实际GIF播放，不能只依据缩略图判断；别选PNG或截图。
- 手机只有一个电脑文件路径：这还不是手机可下载附件，请让制作Agent交付当前入口能取回的GIF。
- 微信没有相同菜单：以你当前客户端为准，先核对是否选中了真实GIF，保留文件后再用个人表情管理入口尝试。
- 某张需要改：告诉制作Agent编号、具体问题和需要保留的地方。改好的新版需重新添加，旧版微信表情不会自动替换。
