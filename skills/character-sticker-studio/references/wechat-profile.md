# 微信普通动态表情专辑规范快照

核验日期：2026-09-28。来源：[微信表情开放平台制作规范及审核标准](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index)。

下表是当时公开官方规范，不是永久规则。实际交付前访问当前官方规范核验，记录日期、来源及变化；工具不可访问时明确“沿用快照，未完成当次核验”，不得伪造已核验。登录和提交属于另一步授权。

| 素材 | 格式与尺寸 | 上限与关键要求 |
|---|---|---|
| 主表情 | 240×240 GIF | 每套8～24张，单张≤500KB，循环；同套统一动态类型 |
| 专辑封面 | 240×240 PNG | ≤500KB，透明，无白色描边，建议半身或全身 |
| 聊天面板图标 | 50×50 PNG | ≤100KB，透明，无白色描边，简洁头部 |
| 详情横幅 | 750×400 PNG/JPG | ≤500KB，不透明，避免白色背景和文字，与角色相关 |

名称8个汉字以内（5个以内更便于展示）、无标点；介绍80个汉字以内；每张含义词4个汉字以内且不重复；版权字段10个汉字以内。长度检查不代替内容审核。

当前脚本内置本快照的普通动态专辑尺寸。若官方规则变化，修改工具与测试后再用，不能只改文字承诺已经适配。个人自用可选 personal，不把平台限制强加给个人项目。

真人肖像按官网要求处理证明及适用授权。由客户向官方提交证件和授权，不在技能包、案例库或公共仓库留存身份证。AI辅助申报按实际表单如实填写，没有“使用Skill即包过”的例外。快照中肖像类不适用单品渠道，不能默认把超额图片拆成肖像单品投稿。

## 对应上传界面
- “横幅” → delivery 内 assets/banner.jpg 或 banner.png。
- “封面” → assets/cover.png。
- “图标” → assets/icon.png。
- 主表情批量上传 → stickers/ 内编号对应的GIF。
- 静态 PNG 备份不是同套动态专辑里要混着上传的主图。

赞赏图片、艺术家主页素材属于额外场景；只有客户需要时读取当前对应规范并制作。不要把普通专辑横幅和艺术家主页横幅的大小限制混为一谈。
