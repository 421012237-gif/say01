# 角色与动作

## 项目角色规范
采用 assets/character-brief.md，在客户项目填写，不在 Skill 本身记住某位客户。
记录证据来源与确认状态：
- 已确认：参考人物、画风、脸部明显特征、头发、衣服、文字需求、数量。
- 待核实：低清照片看不清的形状、手指或背面；不要把“看起来像”写成确定材质、品牌或位置。
- 实现选择：为小图识别作的简化，标记能否调整。
- 禁止改动：客户特别指定的痣、疤痕、首饰、衣服、身份与年龄特征。

配饰用一物一行清单：名称、人物左右侧、具体部位、正面外观、背面外观、什么时候被遮住。双手出现并不意味着强制看见两个戒面；实际遮挡优先。

每件可辨认配饰都给项目内编号，记录参考图／局部依据、颜色、轮廓形状、数量、视觉可确认的材质表现、所属身体部位与佩戴位置。戒指还包括哪只手、哪根手指和装饰面；耳饰包括哪只耳、对数及垂坠方向；项链包括链条、吊坠数量与胸前相对位置；眼镜包括框形、框色和镜片颜色；腕饰包括哪只腕、层数及与其他饰物的相对顺序。只记录该人物实际存在的项目，不强行补齐没有的品类。

照片中可见的细节先保留；用户后来指定的替换或保留要求优先，并记清最终版本。不可辨认的金属种类、背面结构、手指归属不编造为事实。影响本次画面的未明细节先请求对应近照或一句说明；不影响当前小样的可记待核实，不能进入需要该细节的动作后继续假定。

小图可以简化不可见纹理，但不能擅自改变饰品主色、造型、数量、左右和佩戴位置。重要细节在聊天尺寸下看不清时，优先调整构图、手势和空间；无法同时保留时说明具体取舍，不能默默省略或将饰品画到错误位置。

每个动作生成前先推演可见性：人物身体左右 → 部位朝向 → 配饰随部位转动 → 遮挡关系 → 应露出的正面／侧面／背面。交叉手臂从肩膀沿肘、腕追踪，不能按屏幕左右换边。背面缺乏证据时采用符合结构的保守表现并标为推断，不能声称精准还原未知结构。

## 参考与母版
每张参考标注用途：脸、发型、衣服、某件首饰。不要把服装照上的拍照滤镜当成真实鼻子或动物耳朵。照片镜像无法确定时先看更多已提供证据，必要时仅问左右关系；不要猜测后批量复制错误。

新人物按fixed-style.md的固定画风先试一张，用户已经确定角色时直接使用。身份与画风分别确认；不要把“像本人”自动视为“画风已对齐”。后续动作从母版生成，修正原始关键帧可引用该图作编辑目标，同时提醒保留母版身份。

## 可复用提示结构
使用以下字段，按客户实情填写，避免完整复制某个样例的服装与配饰：
- 资产：单图／动作序列／封面／横幅。
- 参考角色：图片1用于身份，图片2用于具体配饰（如适用）。
- 固定项：已确认脸部特征、头发、衣服及配饰清单。
- 动作：每帧具体变化、起始与返回状态、情绪强度。
- 手部：哪只手、手心还是手背、朝向如何变化、戒面何时消失或重新出现。
- 构图：同一人物比例、稳定锚点、完整轮廓、每格四侧有透明间隔；避免贴格边。
- 背景与文字：透明／不透明、是否文字及确切文本；标注无编号和分格线。
- 不要改动：本次无需修改的全部身份要素。

## 动作选择
常见菜单而非固定24项：
问候：你好、早安、晚安、再见。
回应：收到、好的、谢谢、对不起、稍等、没关系、点赞、加油。
互动：比心、抱抱、害羞、亲亲、想你。
情绪：开心、大笑、委屈、哭哭、生气、震惊、疑问、无语、困了。

数量超平台限制时解释并按用户选择处理；不要擅自减少已承诺数量。文字需求和无字动作都可做，不能仅给同一动作换名字。

动作层面要验证眨眼、嘴型、手势与身体变化；常见失败是面孔变了、头部位置漂移、首饰跳动或丢失。延长停顿不能修复错误画面。复杂手势先考虑简化手部关系，保持原含义。
