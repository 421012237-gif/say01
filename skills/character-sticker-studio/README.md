## 使用前需要什么

本机完整流程实测范围为 macOS Codex、Node 22.23.2、sharp 0.35.4。AI 环境需要能读取完整 Skill、查看照片、引用参考图绘制、执行本地工具并交付文件；模型订阅、绘图工具和用量由使用者自备。没有绘图工具时只能处理已有帧。只在普通聊天里上传 SKILL.md 不等于安装完成。

其他支持 Agent Skills 的宿主可按其导入方式接入，但尚未完成本包的完整制作实测，先检查能力并做一个小样。具体入口与证据见 [宿主接入](references/hosts.md)。

## 安装与首次调用

解压得到完整的 `character-sticker-studio` 文件夹。保持 scripts、references、assets 和 examples 的位置；不要只取 SKILL.md，不把客户照片放进安装目录。

把整个目录交给有文件能力的 Agent，发送：

> 请安装这个完整的十一表情包 Skill，按当前宿主识别的安装入口处理；已有同名版本先保留。检查内置画风参考、参考图绘制能力和 GIF 导出运行时，缺失时说明原因。不要全局安装软件，不修改账号设置。后续制作放在独立客户项目。

有执行器时先运行 `node scripts/resolve-style.cjs` 和 `node scripts/runtime-check.cjs`。导出依赖为 Node >=20.9.0 和 sharp 0.35.4；优先使用宿主已有依赖，确需安装时仅在本 Skill 目录安装并先说明影响。两项检查不代替实际绘图和视觉验收。

上传有使用许可的照片，发送：

> 用十一表情包帮我做自己的聊天表情。先给我一个人物小样和一个招手动图，确认人物和画风后再做其他动作。

返修例：

> 修改第 02 张，只改我指出的问题，保留已确认的人物、画风、服装和配饰。

交付例：

> 将通过检查的表情交付为真实透明循环 GIF、静态备份和完整 ZIP，并告诉我怎样添加到微信。

## 能力与使用范围

包含固定画风参考、人物与配饰记录模板、按编号返修、动态 GIF 导出、技术检查及交付打包。视觉判断由 Agent 和使用者实际看图完成，导出成功不等于人物和首饰已经画对。

新人物先做小样；复杂配饰、头纱和遮挡可能需要补图或返修。工具当前导出 240×240、500KB 内的真实循环 GIF；微信正式投稿还需核对当期规范和平台审核。没有完整的独立买家或其他宿主成功证据，不宣称任意照片或所有平台稳定。
