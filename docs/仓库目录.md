## 一级目录用途

| 路径 | 内容与使用方法 |
| --- | --- |
| 根目录的 HTML/CSS/JS | 十一说 Web/PWA 的页面、学习逻辑、AI 文字陪练、跟读判断及离线缓存；入口是 index.html |
| audio/ | 30 条句子示范与 30 条词汇音频，六组场景；AI 动态语音不在这里 |
| assets/ | 十一说品牌 SVG |
| android/ | Capacitor 安卓工程、资源、Gradle 包装器及本地录音、语音、AI 连接插件 |
| scripts/ | 十一说音频生成、资源下载、Web 同步和现有校验脚本；部分生成/下载任务需要网络或用量，按需执行 |
| server/bailian-proxy/ | 阿里云百炼文字陪练中转：请求处理、配置示例及说明；.env.example 仅为占位模板 |
| .github/workflows/ | 手动触发的安卓 APK 构建工作流，沿用已有配置 |
| skills/ | 独立 Skill 集合；当前仅十一表情包，核心、测试、参考与四款 GIF 演示均可读 |
| downloads/ | 对应完整 Skill 的可下载 ZIP 及 SHA256，ZIP 与同版本源码一致 |
| docs/ | 仓库导航、逐文件用途清单及机器可读取的文件索引 |

App 的根路径是 GitHub Pages 和 scripts/sync-web.mjs 的既有入口。表情包放在独立目录，不迁移原 App 资源；安装 Skill 的依赖不要放到 App 的根依赖中。
