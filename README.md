# SAY/01 手机版 V2.4.0 · AI LIVE

面向成年英语零基础用户的免费、无广告、无需登录的手机口语练习工具。

- 在线体验与安装：<https://421012237-gif.github.io/say01/>
- 学习记录默认只保存在当前浏览器
- 普通录音只用于本机临时回放，不上传、不长期保存
- 可选语音识别可能使用浏览器或系统提供的在线语音服务
- 可选 AI 陪练需要联网；个人测试密钥只保存在本机，不进入代码、APK 或进度备份

手机安装：

- iPhone Safari：分享 → 添加到主屏幕
- Android Chrome：右上角菜单 → 添加到主屏幕 / 安装应用
- Android APK：安装 `SAY01-Android-V2.4.0-AI陪练版.apk`；课程第一屏仍按“1 先听 / 2 跟说 / 3 下一句”操作

V2.4.0 在原有 30 条少女声整句、30 个关键词、录音、角色扮演和间隔复习上加入 `AI LIVE`：AI 在 6 个现实场景中扮演对方，每次只说一句、只纠正一个最影响交流的问题，并把一条可复用表达放回后续记忆回声。AI 动态回复暂时只显示文字，避免手机系统朗读回退成男声；固定课程少女声完全保留。

个人免费自测使用 Gemini 免费层。先到 Google AI Studio 创建自己的密钥，再在 App 内“我的 → AI 陪练连接”中粘贴。密钥不进入项目仓库和安装包；正式分享给其他用户前必须改成服务端代理。详细步骤见 `AI陪练使用说明.md`。
