## V2.7.0 解决的核心问题

- 新句第一次只做“听一句”；播放完成后才出现唯一的新动作：自己的台词说一句，对方台词选主要意思
- 听懂或第一次开口通过后自动进入下一句，不再让用户寻找按钮
- 不在同一时刻要求脱稿；用户表达次日到期后才在复习里隐藏英文回来
- 变化表达留给后面的 AI 真实场景，不再要求每句原地完成三遍
- 复习池只取真正到期的句子，不用当天刚学的句子凑题数制造“记住了”的错觉
- 正常重听、慢速、录音对比和今日加练都收进可选区；拼写仍只在弱点出现时介入
- 能力阶段仍保留 `NEW → HEARD → IMITATED → RECALLED → VARIED`，首页完成与稳定掌握分开统计
- “下一句”和“跳过”继续分开；跳过不会增加掌握或伪造进度
- 安卓跟读判断、百炼 `qwen3.7-plus` 文字陪练、本地少女声、诊断与进度备份全部保留

## Android 构建与安全

App ID 继续使用 `com.say01.english`，V2.7.0 为 `versionCode 20700`，覆盖安装用于保留旧版本机进度。构建时通过 GitHub 加密 Secrets 注入 HTTPS 中转地址、可撤销受限口令和已有升级签名；工作流会与 V2.5.0 证书自动比对。受限口令仍可能被有能力分析 APK 的人提取，因此当前 APK 只供本人私测，不公开转发。

本地语音二进制不直接提交进 Git。云端构建从 sherpa-onnx 官方 GitHub Release 下载固定版本并校验 SHA-256；许可证与来源见 `THIRD_PARTY_NOTICES.md`。

当前仍是自主测试版。自动检查、手机尺寸浏览器流程和真实百炼链路通过，不等于安卓真机麦克风、动态音色和覆盖安装已经验收；安装后仍需完成最短真机闸门。
