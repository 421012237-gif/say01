## V2.6.0 解决的核心问题

- 对方台词先听音、再选主要意思；用户台词先听、跟读判断，再隐藏英文主动说出
- “下一句”和“跳过”彻底分开：跳过不会增加掌握或伪造进度
- 语音识别只采用系统第一候选；开麦前停止课程、录音和 Mia 播放，避免 App 听到自己
- 课程与 AI 的安卓语音输入统一走原生 `SaySpeechCheck`；低置信度结果不算通过
- 每句保存能力阶段、尝试次数、最后弱词和复习证据，但不保存原始录音或识别文字
- 21 条用户表达支持脱稿验证和现实信息替换；拼写只在连续失误或弱词出现时介入
- 旧版“已学”只迁移为“接触过”，需要重新验证后才进入真实能力统计
- 复习有几句练几句，不重复凑满五题；用户表达优先脱稿说，对方台词继续练听懂
- 兴趣氛围、版本号、一键运行诊断、备份提醒和动态成绩分母已加入
- AI 本机每日 20 回合，云端默认每日 60 次 / 120000 Token 的单实例保护

## Android 构建与安全

App ID 继续使用 `com.say01.english`，V2.6.0 为 `versionCode 20600`，覆盖安装用于保留旧版本机进度。构建时通过 GitHub 加密 Secrets 注入 HTTPS 中转地址、可撤销受限口令和已有升级签名；工作流还会与 V2.5.0 证书自动比对。受限口令仍可能被有能力分析 APK 的人提取，因此当前 APK 只供本人私测，不公开转发。

本地语音二进制不直接提交进 Git。云端构建从 sherpa-onnx 官方 GitHub Release 下载固定版本并校验 SHA-256；许可证与来源见 `THIRD_PARTY_NOTICES.md`。

当前仍是自主测试版。自动检查和真实百炼链路通过不等于安卓真机麦克风、动态音色和学习效果已经验收；安装后应按 `安卓自测说明.md` 完成发布闸门。
