# 十一说手机版 V2.5.0 · SPEAK / CHECK PRIVATE TEST

面向成年英语零基础用户的免费、无广告、无需登录的手机口语练习工具。

- 在线体验与安装：<https://421012237-gif.github.io/say01/>
- 学习记录默认只保存在当前浏览器
- 普通录音只用于本机临时回放，不上传、不长期保存
- 可选语音识别可能使用浏览器或系统提供的在线语音服务
- 可选 AI 陪练需要联网；百炼长期 API Key 只保存在服务端环境变量，不进入网页、APK 或进度备份

手机安装：

- iPhone Safari：分享 → 添加到主屏幕
- Android Chrome：右上角菜单 → 添加到主屏幕 / 安装应用
- Android APK：本人自测包安装 `十一说-Android-V2.5.0-跟读判断版.apk`；课程第一屏按“1 先听 / 2 说一句马上判断 / 3 下一句”操作

V2.5.0 把跟读闭环改为 `SPEAK / CHECK`：点一次后由 Android 系统识别英语，逐词对照目标句，只判断“是否能被听懂”，并且一次只把一个需要重练的词标成荧光粉；不显示虚假的百分制发音分数。识别文字只在当前页面显示，不写入学习记录。原有 30 条少女声整句、30 个关键词、录音回放、角色扮演、间隔复习和 `AI LIVE` 全部保留。

个人自测使用自己的阿里云百炼北京地域账号。V2.5.0 继续预置独立函数中转地址和可撤销受限口令，首次只需确认联网说明，不再手填技术参数。百炼长期 API Key 只保存在函数环境变量，未进入 APK、网页、源码或项目说明。

Android 支持在构建时通过 `ELEVEN_AI_PROXY_URL` 与 `ELEVEN_AI_ACCESS_TOKEN` 注入已部署中转和可撤销访问凭据。受限口令仍可能被有能力分析 APK 的人提取，所以 V2.5.0 只做本人私下测试，不公开发布；需要立即停用时可在函数环境变量中更换口令。

源码仓库不直接提交约 150MB 的本地语音二进制。首次构建 Android 前运行 `./scripts/fetch-local-voice-assets.sh`；脚本只从 sherpa-onnx 官方 GitHub Release 下载固定版本，并校验写死的 SHA-256。第三方来源与许可证见 `THIRD_PARTY_NOTICES.md`。

当前为自主测试版，尚未完成真人教师内容校对和 10 人学习效果验证。
