# SAY/01 手机版 V2.3.3

面向成年英语零基础用户的免费、无广告、无需登录的手机口语练习工具。

- 在线体验与安装：<https://421012237-gif.github.io/say01/>
- 学习记录默认只保存在当前浏览器
- 普通录音只用于本机临时回放，不上传、不长期保存
- 可选语音识别可能使用浏览器或系统提供的在线语音服务

手机安装：

- iPhone Safari：分享 → 添加到主屏幕
- Android Chrome：右上角菜单 → 添加到主屏幕 / 安装应用
- Android APK：安装 `SAY01-Android-V2.3.3-甜甜少女声版.apk`；课程第一屏按“1 先听 / 2 跟说 / 3 下一句”操作

V2.3.3 把 30 条整句和 30 个拼写关键词全部改成随 App 安装的甜暖少女声离线音频；问句、回应、感谢和求助分别设置语速与音高，课程与复习里的听句、听词优先走 Android 原生播放器。

当前为自主测试版，尚未完成真人教师内容校对和 10 人学习效果验证。
